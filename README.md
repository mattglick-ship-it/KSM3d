# KSM Pavilion Designer

KSM-branded timber pavilion 3D configurator based on the LIVE - KSM Pavilion 3D project.

## Migration status

Repository initialized. Application source migration is in progress; the full application has not yet been synced to this repository.

## Project requirements

- Eastern White Pine timber with visual finish upgrades
- King, Arched King, and Hammer truss options
- Post heights of 8, 9, or 10 feet
- Saved designs and quotes
- Existing KSM payment workflow integration
